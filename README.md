# System Prompt Generator

Free online system prompt builder for AI models like ChatGPT, Claude, and Gemini.

## Features

- **12 Templates**: Code Assistant, Content Writer, Tutor, Data Analyst, Translator, Debugger, Code Reviewer, Brainstorm Partner, Email Writer, Summarizer, SQL Expert, API Doc Writer
- **Customizable**: Role, task, tone, format, constraints
- **Model-Specific**: Optimized suggestions for GPT, Claude, Gemini
- **One-Click Copy**: Copy generated prompts instantly
- **Token Estimation**: Built-in character/word/token counter
- **Quick Examples**: Pre-built examples for common use cases
- **Bilingual**: English and Chinese UI
- **Privacy First**: All processing in the browser

## Deploy

1. Create a new GitHub repository
2. Upload `index.html` and `sitemap.xml`
3. Import to Vercel for automatic deployment
